# 微信文件同步命令行使用指南

适用于 `codex/content-dedup-readonly` 的 M3 实现，尚未发布，保留 M2 账号命令。完整设置界面在 M5，失联文件手动恢复在 M4。本轮开发测试不执行下面针对真实安装的操作。

## 查看配置

安装后，终端中可先设置程序路径，再查看命令和账号：

```bash
app="$HOME/Applications/WeChatDownloadSync.app/Contents/MacOS/WeChatDownloadSync"
"$app" --help
"$app" --list-accounts
```

后续命令中的 `ID` 替换为列表中的完整账号 UUID，命令中的备注加引号。列表展示保存的配置与实际归档位置，允许在后台运行时读取，不表示后台当前正常。`--check` 只读检查各账号授权、目录及归档身份；账号故障不自动覆盖旧配置。

## 修改前停止后台

通过当前安装脚本注册的服务具有 KeepAlive，单纯终止进程会再次拉起。先停止注册的服务：

```bash
launchctl bootout "gui/$(id -u)/io.github.whaoo0.wechat-download-sync"
```

若使用终端直接运行后台程序，先结束该运行。修改型命令取得同一写入锁后才开始迁移或配置；锁被占用会报错退出。不要通过删除 `sync.lock` 绕过锁。

修改完成后，恢复当前安装服务：

```bash
launchctl bootstrap "gui/$(id -u)" "$HOME/Library/LaunchAgents/io.github.whaoo0.wechat-download-sync.plist"
```

这些操作保留应用、账号配置和文件；普通账号管理不需要卸载重装。未通过安装脚本注册服务时，不执行以上服务命令，可按原来的启动方式恢复。

## 首次配置与添加账号

```bash
"$app" --configure
"$app" --add-account --name "工作微信"
```

首次选择一个账号的 `xwechat_files/<账号>/msg/file`，填写备注并授权共享管理根目录；下载目录仅为默认建议。后续添加账号只新增该账号授权，沿用管理根目录。省略 `--name` 时弹窗填写备注。已有活跃配置运行 `--configure` 会保留配置并尝试恢复未完成操作；不会覆盖原账号。

新增账号在添加时建立独立历史基线，已有文件留在微信原处。新文件分别保存到 `<管理根目录>/微信文件/<首次备注>/`；重名时使用安全的新目录，不采用用户已有的同名目录。通过列表查看最终路径。

源目录与管理根目录须在同一文件系统，不能相同或互相包含。重复源目录和别名绑定会被拒绝。M2 不切换共享根目录、不搬迁历史文件，也不自动识别微信昵称或聊天来源。

## 暂停、恢复与修改备注

```bash
"$app" --pause-account ID
"$app" --resume-account ID
"$app" --rename-account ID --name "新的备注"
```

这些命令先在后台停止时保存配置，再启动后台使之生效。暂停后仍维护已有文件的改名、范围内移动和删除，以及已记录的中断任务。恢复后，对暂停期间仍在源目录中的新增文件重新等待稳定，再补同步；不重建历史基线。修改备注只改显示名称，原文件夹保持不变。

文件可在整个管理根目录内整理，包括移到其他账号文件夹；归属仍是原源账号。初始归档文件夹本身丢失或被替换时，停止向该文件夹接纳新文件，能维护的已有链接继续维护。

## 移除与显式恢复

```bash
"$app" --remove-account ID
"$app" --restore-account ID
```

移除不删除实体、微信链接、历史基线和同步记录，清除当前数据库及未完成操作中的源授权，并停止访问和维护该账号。移除后再改名或删除实体，链接不会跟随更新。尚未完成添加的账号也可使用列表中的 ID 移除：保留操作计划和原基线，清除授权并停止自动恢复，不删除已创建目录。显式恢复后继续原操作。

恢复需要重新选择并授权原账号目录，核对路径和目录身份后复用原 UUID 与基线。原目录被重建后不能仅凭同名继承旧身份。再次添加同一目录会提示使用恢复命令，不自动从旧备份恢复授权。

## 授权与未完成配置

```bash
"$app" --reauthorize-account ID
"$app" --reauthorize-root
"$app" --recover-accounts
"$app" --check
```

重新授权只接受原目录，不切换源目录或根目录，不清空基线，也不自动取消用户的暂停设置。一个源授权失效不会阻止其他有效账号；共享根目录不可用则影响全部依赖账号。

添加或迁移中断会保留操作计划。授权有效时，后台启动或 `--recover-accounts` 按记录的目录身份恢复，不覆盖已有目录；只有最终注册成功的新增账号参与同步。若目录身份已变或旧授权失效，保留现场并报告。迁移账号或尚未注册的新账号若授权失效，可对列表中的对应 ID 使用 `--reauthorize-account`，随后再次恢复；保留原操作基线，不直接删库重配。

`--diagnose` 会在已授权的源目录和管理根目录创建并清理临时样本，属于写入操作，须先停止后台。日常只查看配置用 `--list-accounts`，检查授权用 `--check`。

旧版升级的文件位置、备份及回退边界见 [迁移说明](migration.md)，已执行与尚未执行的测试见 [验收记录](validation-report.md)。


## 内容去重与只读

同一账号的新接收文件经内容与附加属性校验后，可复用已有受管理实体。名称或扩展名不同不另存一份，实体当前名称和位置不改变。已有重复副本不自动合并，启用前历史基线及管理根目录的其他用户文件不被接管，账号之间不合并。

共享实体的修改、删除和权限影响所有关联来源。微信侧仅清理一个链接不会反向删除实体；实体移出范围或删除后保留来源记录，但 M3 不提供手动恢复旧链接的入口。真实微信不同扩展名的预览和打开行为仍待实测。

先停止后台，再修改只读默认值或显式应用到已有实体：

```bash
"$app" --set-read-only ID on
"$app" --set-read-only ID off
"$app" --apply-read-only ID on
"$app" --apply-read-only ID off
```

默认开启只读，设置只影响以后新规划的新建实体；已记录的在途操作继续使用规划时策略。新来源复用可写旧实体仍然可写，复用只读旧实体仍然只读，开关不自动改旧文件。

`--apply-read-only` 只遍历该账号已登记且可核对的实体，按实体处理一次。开启时仅移除必要写位；关闭时只恢复本工具有记录移除的写位。原权限未知、原本只读或权限已有外部变化时，不强制变成可写；输出会说明保持原权限或具体冲突。ACL、不可变标记和其他硬链接等不支持安全自动变更时报告，保留文件。如果已有未完成的权限任务，先恢复该任务，再执行本次显式请求；不会只完成相反的旧任务就返回。用户可自行使用系统或编辑器管理权限，本工具不提供编辑副本。

## 去重与权限操作诊断

```bash
"$app" --list-file-issues
"$app" --list-file-issues ID
"$app" --recover-operations ID
```

列表只读取已保存的实体、来源、错误和未完成操作，不执行哈希、清理或格式迁移；显示的权限是记录快照，不代表实时文件一定未被外部修改。配置默认值与实体权限分别展示，授权与目录仍可用 `--check` 检查。

后台会自动恢复已记录操作；也可停止后台后运行 `--recover-operations`，省略 ID 时处理所有未移除账号。它不接纳新文件，只在有效授权范围内核对并恢复记录中的操作。已移除账号须先显式恢复并重新授权，不从旧备份找回授权。

去重交换到完成清理之间，原重复内容可能暂存在操作工作路径。正常完成会清理；失败时保留内容和操作证据。不要按文件名前缀批量删除或把这些文件当作长期备份。源路径被其他文件占用时不会覆盖，错误及操作位置会保留供检查。链接改址的目标会先记入日志；若操作中父目录被重定向出授权范围，停止清理或权限变更，保留内容和任务，待目录范围恢复后重试。

摘要计算分块，每账号每轮有工作预算；合并前和清理前的最终内容复核仍按单个文件完成，大文件可能延长轮次。这不是对微信下载完成的保证，真实暂停续传和沙盒流程仍需后续验收。

## M4：文件回来与指定副本恢复

SQLite v4 保留来源结束原因，区分本程序因实体失联清理与外部移除。原文件以原身份回到管理根目录后，后台约每 30 秒批量复查失联身份，自动恢复程序清理的链接。微信侧自行清理、原因不明、原路径被新生命周期使用或占用时不自动重建；暂停账号仍维护已有关系，移除账号不再访问源。

如果找回的是另一个身份的副本，先自行将它放回根目录，再停止后台，用 `--list-file-issues ACCOUNT_ID` 查实体 ID，然后执行：

```sh
"/路径/WeChatDownloadSync.app/Contents/MacOS/WeChatDownloadSync" --restore-links ACCOUNT_ID ENTITY_ID --file /管理根目录/副本.pdf
```

程序显示账号、原位置、候选大小和逐来源的原名、路径、内容摘要匹配／不同／无法核对，以及跳过原因。可输入来源 ID 子集；输入 `RESTORE` 才执行，其他输入或关闭输入取消。摘要不同或缺失不会替用户作出内容选择；确认意味着将选中旧入口指向你选择的文件。

恢复保留所选文件的名称、位置和权限，不搬动、删除或合并文件。源路径被占、父目录丢失、路径越界、跨账号共享或存在未完成操作时不强行恢复。操作有逐来源日志，中断后可继续核对；预览本身不生成任务。恢复的是本地链接，不保证微信历史消息或服务器附件仍可用。

必要历史元数据长期保留，记录清理暂缓；不保存隐藏原件，也不能从记录找回已丢失的内容。

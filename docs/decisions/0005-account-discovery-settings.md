# 账号发现与简化设置

日期：2026-11-19。用户确认本轮先更新文档再实施；测试只使用临时样本，不扫描真实微信目录。

## C15 选择父目录，再选择账号

首次启动只打开“账号与文件”设置页。用户点击“允许访问微信文件夹…”才打开系统文件夹选择窗口，默认定位到当前用户主目录下的 `Library/Containers/com.tencent.xinWeChat/Data/Documents/xwechat_files`。授权后在设置页内列出可用账号。排除 `all_users` 和 `Backup`（不区分大小写），且只接受具有真实 `msg/file` 子目录的直接子目录；不跟随账号、msg 或 file 的符号链接。单个不可访问子目录不影响其他账号；父目录读取失败仍报错。发现只检查目录结构。用户点击“开始同步”或对应账号的“添加”后才建立基线并开启同步。

直接显示完整账号目录名，不猜测后缀含义、不读取微信昵称、不填写备注。移除桌面备注编辑入口；历史显示名称、归档路径与 CLI 兼容接口保留，不自动改名或搬动文件。

## C16 账号在前，保存位置在后

首次设置在同一页依次授权微信文件夹、选择账号、选择文件保存位置，再点击“开始同步”。设置未完成时可以离开页面或关闭设置，重新打开窗口可继续当前进程中的选择。账号和首次保存位置在确认前只暂存在本次会话。已有账号时，“添加账号”在按钮旁打开浮层，每个候选账号用对应的“添加”按钮确认。点击外部或按 Esc 可关闭。长列表只在浮层内滚动，设置页高度保持原样。沿用共享保存位置，账号新文件仍存入各自的独立子目录。

设置保留“账号与文件”和“通用”两页。前者包含首次设置、账号选择与添加、同步和只读开关、账号文件夹与打开入口。停止／恢复管理和文件关联恢复收起为低频操作。通用放已保存的共享位置、登录启动与应用信息。

“同步新文件”旁说明开启后自动保存微信新收到的文件。关闭只暂停接纳，仍维护已有链接和完成在途操作（C02）。“文件只读”旁说明新保存的文件设为只读，编辑时请另存一份。复用已有实体保留权限（C09）。文件位置旁说明在保存范围内改名或移动会更新微信里的文件链接。

“微信账号”标题右侧显示总体同步状态和已开启账号数。需要处理时，查看当前账号可看到对应原因。

## C17 文件夹访问与账号管理分开

系统文件夹选择窗口授予沙盒访问范围，安全书签用于重启后再次访问。设置中的系统选择窗口附在设置窗口上，用户取消时直接返回。有效授权下隐藏首次授权入口。已有账号的授权无法复用时，浮层内提供授权入口，取消后回到浮层。正在管理的账号实际访问失败时才在账号旁显示“重新授权…”。选错目录等错误在当前设置页或浮层内提示。

新添加账号在既有 source_bookmark 字段保存所选父目录的书签；每次使用时仍校验账号的固定 msg/file 路径、真实目录结构和原目录身份。授权父目录不等于接管全部账号。旧版单账号 msg/file 书签继续可用，下一次添加可重新选择父目录；不自动迁移旧授权。

不新增 SQLite 表或版本：书签仍是不透明授权数据，旧程序的精确路径核对会拒绝父目录书签，不会扩大旧程序访问范围。发现其他账号时可复用某个仍在管理账号的父目录书签；全部账号停止管理后不额外保留独立父目录授权，下次添加重新选择。

此项补充 C04：停止管理清除该账号保存的书签并停止访问其源目录；其他账号仍可能持有同一父目录访问许可，因此不承诺系统级撤销单个子目录权限。恢复已停止账号仍须显式确认并重新核对原目录身份，不能因为发现目录就自动恢复；历史基线与 UUID 不变。
